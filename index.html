Core Problem · 02

The Linear Storytelling Collapse

For ten thousand years, human ideas travelled slowly — setups, digressions, delayed payoffs. Feed-conditioned cognition now rejects that structure before it even loads.

Legacy Communication
Long setups: context first, thesis at minute seven.
Delayed thesis: the payoff lives in the conclusion nobody reaches.
High cognitive friction: the audience must build the frame themselves.
Zero-cost exit didn't exist: leaving a lecture took effort, so staying was default.
Friction
0.82
Feed Conditioning
Feed-Conditioned Cognition
Instant stakes: the brain asks "why should I care?" in under 800 ms.
Thesis-first parsing: conclusions arrive up front; evidence is optional scaffolding.
Micro-segments: meaning is consumed in 15–60 second packets, not arcs.
One-flick exit: leaving costs nothing, so boredom is instantly fatal.

Core Mechanism · 03

The Dopamine & Prediction-Error Loop

Dopamine does not encode pleasure — it encodes prediction error. A feed that never fully surprises, never fully bores, keeps the loop firing indefinitely.

Stage 01
Sensory Interrupt
Motion, contrast, or dissonance hijacks the orienting response before conscious choice exists.
Stage 02
Micro-Curiosity Gap
A withheld detail creates an open loop — the brain pays to close it.
Stage 03
Variable Reward
Intermittent payoff spikes prediction error far harder than any guaranteed one.
Stage 04
Automatic Scroll Reflex
The thumb pre-empts intention. The loop restarts before evaluation begins.
Prediction Error = Reality − Expectation Randomised reward timing maximises error Loops resist extinction, not satisfaction

The Dark Side · 07

Signal Compression vs. Cognitive Shallowing

Every tool that raises engagement velocity lowers nuance bandwidth. The matrix of the trade-off — named honestly, so we can choose it deliberately.

DimensionHigh-Velocity EngagementDeep Critical NuanceThe Trade-Off
Take StructureBinary, decisive, shareableFlattened — qualifiers read as weaknessDisagreement collapses into tribes
Time HorizonOptimised for the first 3 secondsIdeas needing 30 minutes starveComplex truths lose the attention market
EvidenceOne vivid example beats a datasetBase rates invisible; anecdotes omnipresentStatistical thinking outcompetes poorly
EmotionHigh-arousal content propagatesCalm, ambivalent states do not spreadOutrage becomes the native dialect

Ethical line: use velocity to deliver people to depth, not to replace it.

Unethical line: engineered frictionlessness toward behaviour you would not defend face-to-face.

Test: if the hook promised more depth than the payload delivers, you have lied at the API boundary of attention.

Synthesis · 08

Hijacking the Feed Rules for Deep Ideas

Three architectural rules for speakers, engineers, and designers who refuse to let the medium flatten the message.

01

Front-load the Stakes

Answer "why should I care?" in the first sentence, frame, or screen. Context is a seasoning added after the hook lands — never a toll gate before it.

SpeakersWriters
02

Visual State Shift Every 60 Seconds

New diagram, new metric, new plane of motion. One deliberate orienting trigger per minute keeps the reflex awake without fragmenting comprehension.

DesignersUI Engineers
03

One Core Metric Per Frame

Working memory holds roughly four chunks — spend them on one number, one claim, one image. Density is the enemy of retention; whitespace is persuasion.

AnalystsEducators
Blueprint · 09

The 10-Minute Blueprint — Before vs. After

The same talk, pitch, or lecture — rebuilt with ethical algorithmic pacing. Nothing is dumbed down; everything is sequenced for how attention actually works.

PhaseBefore · Default ProtocolAfter · Algorithmic Pacing

Setup 0:30Bio, agenda, methodology — 4 minutes of toll-booth.Progress bar visible; credibility delivered inside the story, not before it.

Ethical constraint: every hook must pay off in substance. Promise depth, deliver depth — never substitute arousal for truth.
